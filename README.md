# DeepSeek 鲸鱼娘桌宠 · 每日任务小助手（DeepSeekPet）

Windows 10 / 11 (x64) · C# WPF (.NET 8) · v1.2

一只住在桌面上的 Q 版 DeepSeek 鲸鱼娘：帮你记住每天要做的事，还能陪你聊天、查资料。

> v1.2 新增：**独立设置界面**（可视化配置 API Key / 联网搜索 / 人设卡，支持连接测试）· **桌宠与托盘右键菜单统一**。  
> v1.1 新增：AI 对话（流式输出）· 人设卡系统 · 自然语言创建提醒 · 联网搜索 · 系统托盘 · 休眠唤醒即时补发。  
> 详细设计与交付说明见 **[docs/AI\_INCREMENT.md](docs/AI_INCREMENT.md)**。

## 功能一览

**桌宠**

- 透明无边框置顶小鲸鱼娘，可自由拖拽；拖动时带轻微倾斜反馈
- 拖到屏幕**左 / 右 / 上边缘松手 → 自动滑出隐藏**，只留一个小把手
- 鼠标悬停把手自动滑出，移开约 1 秒自动收回；重启软件自动恢复隐藏状态
- 单击桌宠 = 展开 / 收起头顶面板（任务 + 聊天）；鼠标离开后桌宠自动"散热"降频
- 右键菜单（**桌宠 / 贴边把手 / 托盘图标三处完全统一**）：显示任务面板 · 新建任务 · 设置 · 清空对话记忆 · 窗口置顶 · 提醒声音 · 开机自启 · 缩放（75%/100%/125%/150%）· 取消边缘隐藏 · 打开数据目录 · 打开日志目录 · 退出
- **系统托盘图标**：左键唤起面板；右键弹出与桌宠一致的统一菜单

**AI 对话（v1.1 新增）**

- 面板内置聊天区：流式逐字回复、增量渲染；对话持久化，重启不丢
- 接任意 OpenAI 兼容服务（默认 DeepSeek；可切 Ollama 等本地模型），密钥从配置文件 / 环境变量读取
- 鲸鱼娘人设卡（`persona.json`）：**改文件免重启生效**；心情 / 好感度动态状态由 AI 自行维护
- 自然语言操作任务：
  - 「明天9点提醒我开会」→ 自动创建一次性提醒（**本地规则秒级完成，离线/无密钥也可用**）
  - 「我有什么待办」→ AI 查询任务列表并回答
  - 「帮我查下明天天气」→ 联网搜索（Tavily / SearXNG，可配置）
- 定时提醒到点时，先由 AI 生成一句人设化提醒语（失败自动回退模板，提醒永不缺席）

**每日任务**

- 任务数量不限；三种重复方式任选：
  - **按天**：每 N 天提醒一次（N=1 即每天）
  - **每周**：一周内任意勾选多个星期几（如周一/三/五）
  - **仅一次**：指定日期单次提醒（AI 创建「明天/后天/X月X日」时使用）
- 到点提醒：桌宠跳跃摆动 + 红色"!"角标 + 头顶气泡说话 + 面板自动弹出并**高亮**该任务 + 系统提示音（可静音）
- 每行任务可勾选"**今日完成**"（当天不再提醒，次日自动复原）
- **重复任务自动去重**：相同名称 + 相同重复规则 + 相同时间无法重复添加；数据载入时也会自动合并重复项
- 面板底部显示"下一次提醒"预告；休眠唤醒后错过的提醒**立即补发**

## 使用说明

1. 运行 `DeepSeekPet.exe`（自包含版无需任何依赖；lite 版需要 .NET 8 桌面运行时）
2. 拖拽摆好位置；拖到屏幕边缘体验自动隐藏
3. 点一下小鲸鱼娘，即可看任务 / 聊天 / 点右上角 **＋** 新建任务
4. 想让它开机自动出现：右键 → 开机自动启动（写入当前用户注册表，无需管理员；开机后静默延迟 3 秒出现，不干扰登录）

**打开设置**：右键桌宠（或托盘图标）→ **设置…**，一个窗口搞定全部配置：

| 页签    | 内容                                            |
| ----- | --------------------------------------------- |
| AI 对话 | API Key（带明文开关）、接口地址、模型、超时/温度/记忆轮数、**一键测试连接**  |
| 联网搜索  | 后端选择（Tavily / SearXNG / 关闭）、密钥、缓存时长、结果条数      |
| 人设卡   | 名字、身份、性格、说话风格、背景、行为规则、口头禅、问候语、摘要；可一键恢复鲸鱼娘默认预设 |
| 关于    | 版本信息、打开数据/日志目录                                |

保存后**立即生效，无需重启**（同时会写回 `appconfig.json` / `persona.json`——喜欢手改文件的同学仍然可以直接编辑，两者等价）。

**更换形象**：把任意命名好的透明底 PNG 改名 `pet.png` 放进数据目录即可（无需重新编译）。

## 数据与日志

| 内容                | 位置                                                                       |
| ----------------- | ------------------------------------------------------------------------ |
| 默认数据目录            | `%APPDATA%\DeepSeekPet\`（pet.db / persona.json / appconfig.json / logs\） |
| 任务 / 设置 / 对话 / 状态 | `pet.db`（SQLite，WAL 模式，全局单连接复用）                                          |
| 人设卡               | `persona.json`（改动免重启生效）                                                  |
| 应用配置              | `appconfig.json`（改动免重启生效；密钥也可用环境变量）                                      |
| 自定义数据目录           | 命令行参数 `--data <目录>`                                                      |
| 开机自启参数            | `--autostart --delay 3`（静默延迟 3 秒）                                        |

- **自动迁移**：v1.0 的 `tasks.json` / `settings.json` 首次启动自动导入 SQLite（旧文件保留为 `*.migrated` 备份）
- **原子落盘**：关键路径（提醒记账）即时提交；普通编辑 2 秒防抖合批（单事务）；异常退出 / 强杀进程后数据完整可恢复（`PRAGMA quick_check` 自检）
- **日志滚动**：按天分文件、单文件 1MB 自动归档、只保留 7 天

## 性能与可靠性设计（本机实测）

| 项目             | v1.0 实测                                 | v1.1 实测（AI 增量版）                                                        |
| -------------- | --------------------------------------- | ---------------------------------------------------------------------- |
| 启动速度           | 约 0.3 ~ 0.6 秒                           | 约 0.4 秒（含数据库打开/迁移）                                                     |
| 空闲 CPU（隐藏待机）   | 0.00%                                   | **0.00%**（10 秒采样；AI 全事件驱动零轮询）                                          |
| 动画中 CPU（漂浮+呼吸） | 20 秒消耗 15.6ms ≈ 0.08% 单核                | 同左（带宽上额外接线的气泡跟随无感）                                                     |
| 内存占用           | 工作集 ~135–142MB（含共享框架页；私有约 80MB）         | 空闲 **124–127MB**；面板/聊天使用后稳态 150–162MB，**空置自动回落**（实测 161.8→149.4MB，无增长） |
| 句柄 / 线程        | 稳定约 670 个句柄 / 19 线程                     | 稳定约 790 句柄 / 26 线程（SQLite + HttpClient 常驻）                             |
| 提醒触发延迟         | **1 毫秒**（计划 17:35:00 → 实际 17:35:00.001） | 同左（机制原样）                                                               |
| 托盘可见时间         | —                                       | 启动后 < 2 秒（托盘先于界面创建）                                                    |

### 关键设计

- **动画**：全部为变换级（平移/缩放/旋转）GPU 友好动画；帧率设上限——活跃 20fps、安静 10fps、**隐藏时 0fps**；25 秒无交互自动降频，贴边隐藏后动画彻底停止
- **流式对话性能**：增量追加只更新单个气泡 `TextBlock`（局部重绘），不重建列表；UI 气泡上限 60 条；后台处理全部在 Task 线程，UI 不阻塞
- **调度**：单定时器动态间隔——离下次提醒 >30 秒时 30 秒一跳，临近时精确到毫秒再跳；**订阅系统电源事件（PowerModeChanged）在唤醒瞬间立即补发**错过的提醒（另有定时器时钟跳变双保险）；启动时对 2 小时内错过的提醒做一次"补提醒"
- **不重复**：按（任务 × 精确到分钟的触发时刻）记账，触发即落盘；同一时刻绝不重复提醒，重启也不会回放
- **不丢失**：关键路径即时提交（SQLite 单事务）；普通编辑 2 秒防抖合批；关机 / 注销（WM_QUERYENDSESSION）与进程退出时强制落盘
- **磁盘写入优化**：空闲时零写入；对话每 50 条做一次环形裁剪；搜索缓存 30 分钟过期；日志滚动归档
- **全局钩子：全项目零使用**。不注册任何 `SetWindowsHookEx`，交互全部走窗口级事件，从设计上规避钩子带来的性能与安全问题
- **DPI / 多显示器 / RDP**：PerMonitorV2 DPI 感知（4K 缩放清晰锐利）；所有窗口（含气泡/面板）定位使用物理像素（Win32 `SetWindowPos`），混合 DPI 多屏不乱跳；每 2 分钟低开销巡检，分辨率/显示器变化自动校正回工作区
- **错误监控与恢复**：UI 线程 / 后台任务 / 进程级三层异常捕获 + Agent 看门狗（单次处理 >180s 强制取消）；所有异常写入滚动日志；界面异常自动吸收并保持运行
- **内存防持续增长**：事件严格解绑、资源一次加载并冻结复用；内置资源守护（工作集 >160MB 记录日志、>220MB 触发一次优化回收；GDI/USER 句柄超阈值告警）
- **单实例**：重复启动只会唤醒已运行的实例（跳动提示），不会出现两只桌宠

## 构建（开发者）

```bash
# 需要 .NET 8 SDK
dotnet build -c Release                 # 轻量版（依赖已安装的 .NET 8 桌面运行时）
dotnet publish -c Release -r win-x64 --self-contained true -o dist/DeepSeekPet-win-x64
```

> 备注：本机开发环境若缺少 `ProgramFiles(x86)` / `ProgramData` 等系统环境变量，  
> 直接 `dotnet build` 会触发 NuGet"Value cannot be null (Parameter 'path1')"。  
> 本项目附带 `tools/dotnetw.py` 包装器（自动补全环境变量后调用 dotnet），用：  
> `python tools/dotnetw.py build DeepSeekPet.csproj -c Release`
